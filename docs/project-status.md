# raid_calc project status

## Classification

Closed milestone: a single-file, offline, browser-based calculator for the
mathematical expectation of data loss over time in hierarchical storage pools
(RAID-like).

## Status

Closed as a v1 milestone (2026-09-29). The engine, editor, optimizer, and Monte
Carlo cross-check reached their documented v1 state; no further development is
planned unless the project's inputs or goals change.

## Evidence

- Design truth: [`design/`](design/) — `raid-calc.md`, `optimizer.md`, `ui.md`,
  `architecture.md`.
- Engine: `src/core/*` (pure functions); UI: `src/ui/*`.
- Tests: `npm test` (vitest); real-browser smoke: `npm run smoke` (Playwright);
  solver speed evidence: `node scripts/bench-solver.mjs`.
- Build artifact: `raid-calc.html`, generated by `npm run build`.

## Deferred

IOPS/latency, scrubbing, aging curves, and operator error were explicit v1
non-goals. Very large machines at multi-year horizons remain expensive by design
(a fast `BuildError`, never a hang).
